# Project 1: Hospital Patient Analytics Using Advanced Regression Modeling

## 🏥 Project Overview
In this project, I conducted statistical analysis of patient data from a Virginia medical center, focusing on predicting mortality risk factors and length of stay patterns. Through my analysis, I aimed to understand the relationships between patient characteristics and healthcare outcomes.

## 📊 Dataset Overview
**Core Statistics:**
- Sample Size: 978 patient records
- Time Period: January - September 2014
- Variables: 13 key indicators including vital signs and demographics
- Primary Outcomes: Mortality and length of stay

## 🔬 Analytical Framework

### Primary Models
1. Mortality Analysis
2. Length of Stay Analysis

### Statistical Methodology
In my research, I employed three complementary approaches:
1. **Model Validation:** 
- I performed ROC curve analysis for performance assessment
- Conducted sensitivity and specificity evaluation
- Determined optimal threshold values

2. **Non-linear Analysis:** 
- I implemented GAM modeling for complex relationships
- Explored variable interactions in depth
- Assessed non-linear patterns in the data

3. **Interaction Assessment:**
- I conducted systematic testing of variable combinations
- Identified significant interactions
- Integrated findings into final models
